pacpad: a terminal app manager for Arch Linux

          
A terminal app manager for Arch Linux. Repo and AUR packages, webapps and TUI launchers, in one TUI. Every change is a plain pacman or yay command, shown to you before it runs.

Keeping an Arch box tidy means remembering a dozen pacman flags, switching to yay for anything from the AUR, and keeping track of the app launchers you made by hand. pacpad puts that in one place without hiding what's underneath.

› one list, many views
Explicit, dependency, orphan and AUR packages are filters on the same list, with a detail pane beside it. Sort by name, size or install date.

          
› launchers get a home
omarchy-style webapp and TUI launchers are easy to create and hard to find again. The Apps tab lists every launcher pacpad made and removes it cleanly.

          
› no terminal handover
sudo's password, pacman's [Y/n] and yay's PKGBUILD review run on a terminal pacpad owns, drawn inside its own screen.

          
› survives pacman upgrades
pacpad reads pacman's database files directly instead of linking libalpm, so a soname bump can't break it.

        

        
what it won't do: replace pacman, keep its own package state, or hide commands from you. Every write is something you could have typed yourself.
